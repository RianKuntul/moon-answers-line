The Moon finally answers back. After four billion years of wishes, howls
and late-night promises, the Moon confesses what it has actually been doing
with them all: hearing every wish — and ignoring most of them on purpose.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
